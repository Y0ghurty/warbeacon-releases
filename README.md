# Warbeacon downloads

Warbeacon is a World War II online war game on a real-world hex map, in early development (pre-alpha).

**[Download the latest version for Windows](https://github.com/Y0ghurty/warbeacon-releases/releases/latest/download/Warbeacon-Windows.zip)**

1. Unzip it and run `Warbeacon.exe`. If Windows says it protected your PC, click **More info**, then **Run anyway**.
2. Click **Join online**. The server address is already filled in.

Older versions are under [Releases](https://github.com/Y0ghurty/warbeacon-releases/releases). This page only hosts the downloads; the game's code is private.
